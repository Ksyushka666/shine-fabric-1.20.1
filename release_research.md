# Release research

Официальная страница Shine: VFX на CurseForge показывает, что предоставленный `shine-3.0.jar` является релизом только для Minecraft 1.21.11 и Fabric. На странице релизов перечислены версии 1.21.11, 1.21.1 и 26.x; готового официального релиза для Minecraft 1.20.1 не найдено.

Источник: https://www.curseforge.com/minecraft/mc-mods/shine-vfx/files

Официальный исходный репозиторий: https://github.com/tapeQz/Shine

Для Minecraft 1.20.1 найден Sodium `mc1.20.1-0.5.11`; его пакеты используют namespace `me.jellysquid.mods.sodium`, тогда как исходный Shine 3.0 использует API более новых версий Sodium и Minecraft.
